## Overview

v0.23.0rc4 is the fourth release candidate of v0.23.0: v0.23.0rc3 rebuilt on icpp-pro 7.0.0rc4, which fixes a security bug in the Candid decoder. Every wasm built on icpp-pro up to 7.0.0rc3, v0.23.0rc3 included, has the bug, so upgrade those canisters. For apps nothing else changes since rc3. Releases now have release notes.

### Highlights

- Candid decoder security fix: a message that ends early now traps with "Not enough bytes left" instead of being read past its end ([#71](https://github.com/onicai/llama_cpp_canister/pull/71))
- Every release now has notes: a summary, the commits since the previous release, then how to reproduce the wasm ([#70](https://github.com/onicai/llama_cpp_canister/pull/70))

### Upgrade notes

- Upgrade every canister built from v0.23.0rc3 or earlier; an upgrade from rc3 keeps the uploaded models and prompt caches ([#71](https://github.com/onicai/llama_cpp_canister/pull/71))
- Replies are smaller where they repeat a Candid type, e.g. a directory listing: same values, different bytes ([#71](https://github.com/onicai/llama_cpp_canister/pull/71))

### icpp-pro

- icpp-pro [7.0.0rc4](https://github.com/icppWorld/icpp-pro/releases/tag/v7.0.0rc4): the decoder fix, shared Candid type tables, and linear decoding of a vec of records ([#71](https://github.com/onicai/llama_cpp_canister/pull/71))

### Scripts and tooling

- Release notes: `docs/release-notes/` holds each release's summary, written from `scripts/make-release-summary.txt` ([#70](https://github.com/onicai/llama_cpp_canister/pull/70))
- `scripts/make-release-desc.sh <tag>` lists the commits since the previous release; `release.yml` refuses a tag without notes ([#70](https://github.com/onicai/llama_cpp_canister/pull/70))
- For contributors, `make test-llm-native` runs under `icpp run-native`, icpp-pro's memory guard; `scripts/memory_guard.py` is gone ([#71](https://github.com/onicai/llama_cpp_canister/pull/71))
